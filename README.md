# リズムバラエティ v5

PWA / GitHub Pages向けのオリジナル・リズムミニゲーム集です。
既存IPの画像・音楽・キャラクターは同梱しません。

## v5 highlights
- 7ステージ
- 深海以外にロボ工場 / DJ / 忍者テーマを追加
- コール&レスポンス、待ち、裏拍、フェイクを強化
- AudioContextをマスタークロックとして使用
- v1〜v4セーブデータ移行
- PWA / オフライン対応

## Development
```bash
npm install
npm run typecheck
npm run build
npm run dev
```
